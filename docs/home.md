# ブログホーム・ゲーム一覧

- `/` は最新記事4件、おすすめ記事4件、ゲームへの入口を表示します。
- 最新記事は `posts` セクションの公開記事を日付降順で4件表示します。
- おすすめ記事は `data/home.yaml` に記述した順で4件表示します。`page` は記事のcontent配下のパス、`label` はカードの分類表示です。
- 記事一覧全体は従来どおり `/posts/` から閲覧できます。
- `/games/` は各ゲームの画面プレビュー、ゲーム名、説明、プレイ用リンクを表示します。
- ゲームカードは `layouts/_partials/portal/game-card.html`、記事カードは `layouts/_partials/portal/post-card.html` を共有します。
- `assets/css/extended/portal.css` の表示設定はホームとゲーム一覧に限定し、記事本文やゲーム本体のデザインを変えません。

## ゲームの画面プレビュー

標準ではゲームページを `sandbox` 付きiframeで表示します。スクリプト、操作、セーブ領域へのアクセスを許可せず、初期画面だけを縮小表示します。BGMも再生しません。カードの「遊ぶ」リンクからゲーム本体を開くと通常どおり操作できます。

JavaScriptでしか画面を描画できないゲームは、スクリーンショットを用意し、ページの `params.previewImage` にページ内の画像パス（例: `images/preview.webp`）またはサイト内の画像URLを指定してください（推奨比率16:10）。画像を指定するとiframeの代わりに表示します。

公開前の記事を手元に置いたまま確認するときは、ローカル専用の追加Hugo設定で `ignoreFiles` にその記事のパスを指定できます。未公開の記事やローカル設定をコミットしないでください。

## ビルド環境の互換性

Cloudflareのログで確認したHugoは0.147.7です。ホームのデータ取得はこのバージョンでも利用できる `site.Data` を使用します。`hugo.Data` は0.156.0以降の機能なので、CloudflareのHugoを更新するまでは置き換えないでください。ローカルの新しいHugoでビルドが通るだけでは、本番との互換性は確認できません。
