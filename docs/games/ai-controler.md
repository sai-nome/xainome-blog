# AI Controler

小さなPCからAI企業を育て、最終的にロケットを打ち上げるブラウザ放置ゲームです。

- 一覧: `/games/`
- ゲーム: `/games/ai-controler/`
- ローカル: `http://localhost:1313/games/ai-controler/`
- 共通の追加手順・ビルド方法: [README.md](README.md)

## ファイル

専用HTMLは `layouts/ai-controler/single.html`、部品は `layouts/_partials/games/ai-controler/` にあります。
`assets/games/ai-controler/` の各ファイルの役割は次のとおりです。

| ファイル | 役割 |
| --- | --- |
| `engine.js` | 数値計算、購入・強化・研究、セーブ検証・移行、オフライン進行 |
| `game.js` | 画面更新、操作、自動保存、バックアップ、打ち上げ演出 |
| `guide.js` | アイテムや効果の説明 |
| `help-ui.js` | ヘルプ・初回操作説明 |
| `skill-tree.js` | 解放条件、費用、実行可否、ツリーの配置・接続線 |
| `skill-tree-ui.js` | ツリー描画、購入・強化タブ、Tab開閉・拡大縮小 |
| `dialog-ui.js` | ダイアログ枠外クリックの処理 |
| `sound.js` | Web Audioの効果音・音量設定 |
| `music.js` | SFアンビエントBGM・音量設定 |
| `style.css` | ゲーム専用の表示・レスポンシブ対応 |

JS・CSSはHugoでハッシュ付きURLに変換します。手動の `?v=...` 更新は不要です。
テストは `scripts/games/ai-controler.test.cjs`、ツリー操作の補助は `scripts/games/ai-controler-ui-harness.cjs` です。
ゲーム内の `AIEmpire` / `EmpireSkillTree` などの内部API名は既存モジュールとの互換性のため維持しています。

## 現在の遊び方・仕様

- 案件をクリックして資金を稼ぎ、GPUとAIを導入します。パズルはありません。
- 購入・強化はスキルツリーの2つのタブで行います。Tabまたは画面のボタンで開き、枠をクリックして実行します。
- GPUの計算能力をAIの優先度で配分します。電力・冷却不足では効率が下がり、サーバーラックの枠が足りないとGPUを設置できません。
- クリック報酬と各AIを資金で5段階強化できます。AI強化は同じ計算能力での成果を増やし、電力や配分量は増やしません。
- 研究AIが研究ポイントを生産し、水・冷却設備、半導体製造、自社GPUの開発へ進みます。設備は進行に合わせて表示されます。
- 水設備は原水を高純度水へ処理し、液冷や工場を支えます。高純度水を直接購入する操作はありません。
- Coding AIは収益の仕事と工場制御ソフトの開発を切り替えられます。後者は工場の生産を強化します。
- 市販GPUと自社GPUは別に数え、ラックを共有します。自社GPUの設計強化は最初の組み立て後に利用できます。
- 自社GPUのCPはLv.1から順に8・12・18・26・36。Lv.2以降の開発費は200・450・900・1,600 RPです。
- 自社GPUを組み立てると宇宙開発が開きます。Lv.5でRocket AIを1,200 RPで研究・導入でき、直接収益は生みません。
- ロケット機体は90,000、燃料は45,000、AI航行システムは60,000の資金が基本費用です。ほかに半導体・水・研究ポイント等も必要です。大型案件の報酬で費用を軽減できます。
- 起動ステーションの設計は大型案件、AI航行システムは宇宙開発に配置します。ツリーではRocket AIを自社GPU設計の下、AI航行システムを最下段に配置します。
- 打ち上げにはLv.5の自社GPU8基以上、Rocket AI、完成したロケット部品、十分な電力・冷却が必要です。打ち上げ後はエンディングを表示し、生産を終了します。
- 初めての購入・導入には演出と効果音があります。BGM・効果音は設定画面で個別に調整できます。ブラウザーの仕様上、音はユーザー操作後に開始します。

費用や条件の正本は `engine.js`、表示時の条件・説明は `skill-tree.js` と `guide.js` です。

## セーブの互換性

ゲームのパスを移しても、**同じオリジン（スキーム・ホスト名・ポート）なら既存の進行を引き継ぎます**。
製品名・フォルダー名の整理に合わせて次の保存キーを変更してはいけません。

- 本体: `xainome.ai-empire.v1`
- 効果音: `xainome.ai-empire.sound`
- BGM: `xainome.ai-empire.music`
- 操作説明: `xainome.ai-empire.controls.v3`
- Tab設定: `xainome.ai-empire.tree-tab`
- 多重起動防止: 本体キーを使う `navigator.locks`、非対応環境では `xainome.ai-empire.v1.lease`

保存形式はバージョン1を維持し、旧版にない項目は読み込み時に補完します。
オフライン進行は最大8時間です。設定画面でJSONバックアップの書き出し・読み込みができます。
異なるドメイン・ポートへの移転にはバックアップを使用してください。
