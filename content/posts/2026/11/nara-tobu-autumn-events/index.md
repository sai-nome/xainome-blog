奈良市東部で、2026年10月17日に**東里地区の草刈りイベント**、翌18日に**大柳生地区・阪原町のコスモス祭り**が開催されました。

草刈りをチーム対抗のイベントにしたり、コスモス摘みや芋掘り、餅つきを楽しめたりと、地域の暮らしや農業に身近な催しです。一方で、地域住民や開催した方々からは、予算や収穫した芋の扱いについての声もありました。

今回は、2つのイベントの内容と、地域の方々から聞いた話をまとめてみます。

## 奈良市東部で開催された2つの秋イベントの概要

| 項目 | 東里地区の草刈りイベント | 阪原町のコスモス祭り |
| --- | --- | --- |
| 開催日 | 2026年10月17日 | 2026年10月18日 |
| 地区 | 奈良市東里地区 | 奈良市大柳生地区・阪原町 |
| 会場 | 奈良市立興東小学校付近 | 阪原町営農組合ライスセンター |
| 終了までの時間 | 約2時間 | 約6時間 |
| 主な内容 | 5チームに分かれ、レーンごとに草刈り | コスモス摘み、芋掘り、餅つき、飲食物の販売 |

この記事は、2026年に開催されたイベントの記録です。以下の料金も開催時のもので、次回の開催日や内容を案内するものではありません。

## 東里地区の草刈りイベント｜5チームでレーンごとに草刈り

**東里地区の草刈りイベントは、10月17日に奈良市立興東小学校付近で開催され、約2時間で終了しました。** 参加者は5チームに分かれ、それぞれのレーンで草刈りを進める形式です。

優勝チームには賞品が用意されていました。草刈りにチーム対抗の要素や賞品が加わると、作業そのものがイベントになるのが面白いところですね。草刈りは速く刈れたか？綺麗に刈れているかで判定します。審査員は見学者全員で綺麗に刈らないと見学者からのポイントがもらえないことになります。

{{< figure src="images/higashisato-grass-cutting.webp" alt="東里地区の草刈りイベントで、ロープで区切られた草地を刈払機で刈る参加者" caption="2026年10月17日、東里地区の草刈りイベント。レーンごとに草刈りを進めます。" width="1440" height="810" align="center" >}}

### 草刈りが進み、地域の催しにもなる

このイベントのよいところは、草刈りを進めながら、地域の催しにもできることだと思います。

草を刈るという目的は同じでも、チームで取り組み、優勝を目指す形になると、参加するきっかけも変わってきそうです。地域に必要な作業に楽しみを加える、一つの工夫だと感じました。

{{< figure src="images/higashisato-grass-cutting-field.webp" alt="草が刈られた東里地区のイベント会場と、道具を持って集まる参加者" caption="草刈りが進んだ会場の様子。" width="1440" height="1080" align="center" >}}

### 地域住民からは予算を心配する声も

一方で、**地域住民からは、イベントの予算を懸念する声もありました。**

草刈りができて、イベントとしても楽しめるのはよいことですが、続けるためのお金をどう確保するかは気になるところです。具体的な予算額や収支は確認していません。

私としては、催しとしての楽しさと、無理なく続けられる運営の両方が大切なのだと思います。

## 阪原町のコスモス祭り｜コスモス摘み・芋掘り・餅つきを実施

**阪原町のコスモス祭りは、10月18日に大柳生地区の阪原町営農組合ライスセンターで開催され、約6時間で終了しました。**

会場では、コスモス摘みや芋掘り、餅つきが行われました。花を楽しむだけでなく、収穫や食にも触れられるイベントです。

{{< figure src="images/sakahara-cosmos-field.webp" alt="阪原町の田園風景の中に広がる、ピンクと白のコスモス畑" caption="阪原町のコスモス畑。" width="1440" height="1080" align="center" >}}

### コスモス摘みは100円、芋掘りは袋いっぱいで500円

開催時の料金や販売内容は、次のとおりです。

| 体験・販売内容 | 開催時の料金・内容 |
| --- | --- |
| コスモス摘み | 100円 |
| 芋掘り | 袋いっぱいで500円 |
| 餅つき | 実施あり |
| 炊き込みご飯 | 200円ほど |
| お酒 | 販売あり |

コスモス摘みが100円、芋掘りが袋いっぱいで500円というのは、気軽に参加しやすい価格だと感じます。炊き込みご飯などの販売もあり、体験と一緒に食を楽しめる内容でした。

{{< figure src="images/sakahara-potato-digging-venue.webp" alt="阪原町のコスモス祭りで、テントのそばの畑で芋掘りをする参加者" caption="2026年10月18日、コスモス祭りの芋掘り会場。" width="1440" height="1080" align="center" >}}

### 開催した住民からは、売り上げを期待する声

開催した住民からは、よい売り上げを見込めるという話がありました。

これは開催した方から聞いた見込みであり、確定した売上額や利益を示すものではありません。それでも、地域の催しによって自治会が潤い、次回のイベントをより良いものにできる点は、運営を考えるうえで興味深いところです。

### 芋を傷つけずに掘る難しさと、畑に残る芋の課題

芋掘りは、芋を傷つけずに掘り出すのが難しい体験でもあります。

{{< figure src="images/sakahara-potato-digging.webp" alt="阪原町のコスモス祭りで、畑の畝に沿って芋掘りに取り組む参加者" caption="畑に入って芋掘りを楽しむ参加者。" width="1440" height="1080" align="center" >}}

開催した方々からは、**傷ついた芋がその場に残ってしまう**と聞きました。袋いっぱいに持ち帰れる楽しさがある一方で、傷ついた芋がその場に残されてしまうのは非常にもったいないなと思いました。

それでも地域の人達は楽しんでくれてる人たちが優先ということで傷ついた芋を諦めて、動物を飼ってる人にあげていました。傷ついた芋を有効活用できるような工夫があればと思いました。

## 地域のイベントを楽しむことと、続けていくこと

東里地区の草刈りイベントは、地域に必要な作業を催しにする工夫が印象に残りました。阪原町のコスモス祭りは、花や収穫を楽しむ体験に、飲食物の販売も組み合わせたイベントでした。

地域の方々の話を聞くと、楽しさの一方に、予算や収穫物の扱いといった運営上の課題も見えてきます。参加する側からだけでは分からないこともありますね。

地域の催しを楽しみながら、準備や運営についても少しずつ知っていきたいと思います。ではでは。
