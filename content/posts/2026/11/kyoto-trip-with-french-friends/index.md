**フランスの友人2人と、京都へ2泊3日の旅行に行ってきました。** 東本願寺、東寺、高台寺、錦市場、嵐山モンキーパーク、伏見稲荷大社の6か所を巡り、高台寺では夜のライトアップも楽しみました。

車は加茂駅近くの駐車場に3日間停めて、合計600円。宿泊先はGuesthouse signで、ドミトリーに1泊3,500円で泊まりました。

3人でたくさん歩き回ったので疲れもしましたが、とても楽しい旅行でしたね。この記事では、京都で訪れた場所を写真とともに振り返り、今回の宿泊費と駐車場代をまとめます。

## 京都2泊3日旅行の概要と費用

今回の旅行の内容は、次のとおりです。

| 項目 | 今回の旅行内容 |
| --- | --- |
| 旅行先・日数 | 京都・2泊3日 |
| 同行者 | フランスの友人2人（私を含めて3人） |
| 訪れた観光地 | 東本願寺、東寺、高台寺、錦市場、嵐山モンキーパーク、伏見稲荷大社 |
| 夜の観光 | 高台寺のライトアップ |
| 宿泊先・部屋タイプ | Guesthouse sign・ドミトリー |
| 宿泊料金 | 1泊3,500円（2泊分で7,000円） |
| 車を停めた場所 | 加茂駅近くの駐車場 |
| 駐車場代 | 3日間で合計600円 |

宿泊料金と駐車場代は、今回利用したときの金額です。食費、移動費、拝観料などは上の表に含めていません。以下は観光先ごとの記録で、訪問順を示したモデルコースではありません。

京都のお寺巡りでは、**東本願寺と東寺**を訪れました。友人たちと一緒に観光地を回る時間も、今回の旅行の楽しみの一つでした。

東本願寺では、門やお堂の姿を写真に残しました。写真を見返すと、建物の大きさが伝わってきますね。

## 伏見稲荷大社｜朱色の鳥居が続く参道へ

**伏見稲荷大社も、今回の京都旅行で訪れた場所の一つです。** 入口の大きな鳥居と、鳥居が連なる参道を写真に残しました。朝6時くらいに行ったのですが、すでに大勢の観光客でいっぱいでした。恐らく4時ぐらいに行かないと、ガラガラにはならないと思われます。もし行くなら早い時間帯に行くことをおすすめします。

3人であちこちを歩き回り、京都の景色を一緒に楽しめました。たくさん歩いた疲れも、旅を振り返ると思い出の一部ですね。

## 加茂駅近くの駐車場は3日間で合計600円

今回、**車は加茂駅近くの駐車場に3日間停めて、合計600円**でした。

泊まりで旅行すると、車を停めておく費用も気になります。今回は3日間で600円だったので、駐車場代を抑えられてありがたかったです。京都の近くが良かったのですが、大体1000円超えることも多いですからね。

ここでは利用時の支払額を記録しています。駐車場の名称や料金条件はこの記事には載せていません。

## Guesthouse signのドミトリーは1泊3,500円

京都での宿泊先は、**Guesthouse signです。ドミトリーに1泊3,500円で泊まりました。** 2泊分にすると、宿泊費は7,000円です。

今回は友人たちと観光地を歩き回る旅だったので、宿泊費も抑えながら2泊3日を楽しめたのはよかったですね。

1泊3,500円は今回の宿泊料金で、今後の予約でも同じ金額になるとは限りません。京都駅近くは大体万超えることも多いです。ドミトリーなので安めの値段ですが、いびきで寝れない人にはかなりきついと思います。私は多少の音ぐらいなら大丈夫ですが。

## また京都へ、そして友人と日本やフランスを巡りたい

今回の京都旅行は、東本願寺、東寺、高台寺、錦市場、嵐山モンキーパーク、伏見稲荷大社を巡った2泊3日でした。

たくさん歩いて疲れもしましたが、**フランスの友人2人と一緒に回れて、とても楽しかったです。** 観光地に行けたことはもちろん、この2人と旅行できたことがよい思い出になりました。また一緒に、日本のほかの場所やフランスを回りたいですね。

京都にも、今回まだ回れていない観光場所がたくさんあります。次に行くときは、今回訪れられなかった場所も楽しみたいと思います。ではでは。
